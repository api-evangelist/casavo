# Casavo

> Casavo Management S.p.A. is an Italian proptech company (Milan, founded 2017) running a digital
> residential real estate platform in Italy, Spain, France and Portugal. It began as an iBuyer and
> now operates as a marketplace and brokerage connecting sellers, buyers and partner estate agents,
> with mortgage brokerage, document management and renovation services attached. Its developer-facing
> surface is Realisti.co — marketed as Casavo Virtual Tools — a versioned REST API for creating and
> managing property virtual tours.

## API

- [Casavo Virtual Tools (Realisti.co) API](https://editor.realisti.co/api/v4/): Versioned REST API
  for virtual tours. The v4 collection index is anonymous and lists 28 resources (house, floor,
  view, target, poi and their draft twins, photo, photozipball, analytics, plans, agency,
  agencyplan, agencyprofile, agentgroup, agent, apikey, category, auth, userprofile, subscribe,
  sync/property, sync/agency, sync, syncagency). Every collection answers 401 without credentials.
  v2 and v3 are still served alongside v4.
- Documented capabilities (per Casavo's own, now-offline help centre): create an empty virtual
  tour, retrieve the URL of an existing tour, activate/deactivate a tour.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, MCP server or A2A agent card is published.
- The API reference URL Casavo published, https://editor.realisti.co/api/v4/docs/, returns 404.

## Authentication

- API key, issued through an invitation-only sandbox area and enabled per plan
  (`plan.can_api_use_api_key`). Key transport is not documented publicly.
- Session/cookie path for the editor web application at https://editor.realisti.co/login/.
- No OAuth 2.0 and no OpenID Connect.
